# NOTECOACH 2.0

Aplicação de notas e análise de futebol para treinadores e analistas.

## Novidades 2.0
- Match Mode
- Jogos e adversários
- Ações rápidas: golo, remate, assistência, recuperação, perda e bola parada
- Notas por categoria
- Etiquetas
- Gravação persistente em IndexedDB
- Transcrição por voz quando suportada pelo navegador
- Relatório automático organizado por áreas do jogo
- Exportação do relatório
- Interface responsiva para PC, tablet e telemóvel
- Funcionamento local/offline para os dados desta fase

## Instalação
npm install
npm run dev

## Próxima evolução
Ligação a uma API profissional de transcrição e IA para transformar observações em relatórios técnicos completos.
