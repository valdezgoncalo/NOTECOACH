# NOTECOACH 1.1

Bloco de notas com gravação de voz e transcrição no navegador.

## Funcionalidades

- Criar, editar e apagar notas
- Pesquisa
- Gravação de áudio
- Pausar / continuar
- Reprodução do áudio
- Áudio guardado em IndexedDB
- Notas guardadas em LocalStorage
- Reconhecimento de voz quando suportado pelo navegador
- Interface responsiva para PC, tablet e telemóvel

## Instalação

```bash
npm install
npm run dev
```

Depois abrir http://localhost:3000

## Vercel

Importar o repositório GitHub e deixar o Vercel detetar Next.js automaticamente.
